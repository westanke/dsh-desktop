## 一、修掉的阻塞项

| 问题 | 根因 | 处理 |
| --- | --- | --- |
| 安装后无桌面/菜单快捷方式 | jpackage 生成的 `.desktop` 只留在 `/opt/dsh-desktop/lib/` 下，**没有装进 `/usr/share/applications`** | 打包阶段补 `/usr/share/applications/dsh-desktop.desktop` + 5 档 hicolor 图标；postinst 为已有用户桌面临一份；首次启动再兜一次 |

| 只带图片、不带文字的消息整条消失 | `user/message` 分支按「`contentText` 为空就 continue」跳过 | 改为「文本与图片都为空才跳过」，图片 id 收进 `ChatItem.User.attachments` |
